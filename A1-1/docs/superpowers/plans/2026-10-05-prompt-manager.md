# 프롬프트 관리 프로그램 작업 계획

> 실행 담당: 사용자의 구현 지시에 따라 실행했다. 구현 시에는 superpowers:executing-plans를 참고한다. 사용자 변경 지시에 따라 Git·GitHub 작업은 에이전트가 수행한다. VS Code 설정·로그인 및 제출용 스크린샷 촬영은 사용자가 수행한다.

**Goal:** 필수 요구사항을 만족하는 Python 콘솔 프롬프트 관리 프로그램을 만든다.

**Architecture:** `main.py`에 기능별 함수를 두고, 리스트 안의 딕셔너리로 데이터를 관리한다. `main()`이 실행마다 기본 데이터를 생성하고 같은 리스트를 각 기능에 전달한다. 파일이나 DB에 저장하지 않으므로 재실행하면 기본 데이터로 돌아간다.

**Tech Stack:** Python 3.10 이상, 외부 라이브러리 없이 기본 문법 사용.

**Spec:** 프로젝트 루트의 `미션 - AI 활용 학습.pdf` 전체 10쪽. 필수 산출물은 2쪽, 기능은 3~5쪽, 제약은 6쪽, 예시는 7~10쪽.

## 범위와 제약

- 필수 기능: 메뉴, 기본 데이터, 추가, 전체 목록, 카테고리별 조회, 검색, 상세 보기, 즐겨찾기 추가·해제 및 목록.
- 각 프롬프트의 필드: `title`, `content`, `category`, `favorite`.
- 원문은 이전 미션 프롬프트 3개 이상을 요구한다. 사용자의 후속 요청 “니가 직접 만들어”에 따라 새 예시 3개를 작성한다. 원문과의 출처 차이를 README에 명시한다.
- 새 항목의 즐겨찾기 기본값은 `False`이다.
- 기능별로 함수를 분리한다. 클래스, 웹 UI, 외부 API 등은 필요하지 않다.
- 보너스 제외: JSON 저장·불러오기, Markdown 내보내기, 수정·삭제, 조회수 및 인기순 정렬.
- Git·GitHub 작업은 에이전트 담당이다. 이미 연결된 상위 저장소와 원격을 그대로 사용하며 저장소 초기화·재초기화, 중첩 저장소 생성, 원격 재설정을 하지 않는다.
- 상위 `.gitignore`를 그대로 적용한다. 새 `.gitignore`를 만들거나 기존 파일을 변경하지 않는다.
- 같은 저장소의 다른 과제 파일·변경 사항·이력을 보존한다. 스테이징과 커밋은 이번 `A1-1` 과제의 명시적인 파일 경로로 한정하며, 저장소 전체를 일괄 스테이징하지 않는다. 기존에 스테이징된 다른 작업도 커밋에 포함하지 않는다.
- VS Code 작업은 사용자 담당으로 유지한다.
- 한 번에 전 기능을 구현하지 않고 아래 기능 단위로 구현·검증·커밋하여 의미 있는 커밋 최소 10개를 남긴다. 기존 이력을 조작해 기록을 만들지 않는다.

## 구현 결정

- 메뉴: `1` 추가, `2` 전체 목록, `3` 카테고리별 조회, `4` 검색, `5` 상세 보기, `6` 즐겨찾기 전환, `7` 즐겨찾기 목록, `0` 종료.
- 카테고리는 고정 목록 선택 방식을 사용한다: 텍스트 생성, 이미지 생성, 영상 생성, 페르소나, 자동화, 기타. PDF는 고정 목록 선택과 직접 입력 중 하나를 허용한다.
- 표시 번호는 전체 리스트의 위치 + 1이다. 검색·카테고리·즐겨찾기 목록에서도 원래 번호를 유지하여 상세 보기 및 즐겨찾기 대상이 혼동되지 않게 한다.
- 제목·내용은 공백뿐인 입력을 거부한다. 검색어도 빈 입력을 거부한다.
- 검색은 제목 또는 내용의 부분 일치로 하고, 영문 대소문자를 구분하지 않는다.
- 잘못된 메뉴는 안내 후 메뉴로 복귀한다. 필수 입력과 카테고리 입력은 다시 받는다. 상세 보기·즐겨찾기의 잘못된 번호는 안내 후 메뉴로 복귀한다.

## 주의할 입력과 검증 위치

1. 공백뿐인 제목·내용·검색어: 추가 및 검색 단계에서 재입력을 확인한다.
2. 문자·소수·음수·0·범위 초과 번호: 메뉴·카테고리·상세·즐겨찾기 단계에서 예외 없이 안내하는지 확인한다.
3. 검색 결과에 원래 3번 항목만 나오는 경우: 결과에 3번이 표시되고 상세 조회도 같은 항목인지 확인한다.
4. 빈 전체 목록·해당 카테고리 0건·검색 0건·즐겨찾기 0건: 각 목록에서 안내를 확인한다. 전체 빈 목록은 검증용 데이터로만 확인한다.
5. 즐겨찾기 반복 전환 및 재실행: 같은 실행에서는 상태가 유지되고 재실행하면 초기 상태인지 확인한다.

필수 프로그램 요구사항은 1~11단계에 대응한다. Git·GitHub 작업은 0단계, 기능별 커밋, 5단계 브랜치 병합 및 최종 확인에 반영했다. 사용자 확인에 따라 기존 상위 저장소·원격·`.gitignore`를 재사용하며 초기화 작업은 제외했다. 다른 과제의 파일·변경·이력은 보존한다. VS Code 작업과 스크린샷 촬영은 사용자 담당이다. 보너스 기능은 모두 제외했다. 필수 프로그램 기능 구현 및 테스트를 완료했다. Git 원격 반영을 완료했으며 VS Code 작업과 스크린샷 촬영은 사용자 담당으로 남긴다.
