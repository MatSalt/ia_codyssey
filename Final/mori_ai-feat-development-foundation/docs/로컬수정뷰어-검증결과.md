## 구현과 공개 인터페이스

모든 서비스는 caller-owned transaction을 사용한다. HTTP route는 기존 세션·변경요청 CSRF/Origin·envelope·no-store/request_id 경계를 사용하며 body/query 추가 필드는 422다. owner/deleted album 및 다른 album/removed page는 404다. caption/publish는 album row lock을 공유해 삭제·서로의 작업과 원자 경쟁하며 page 수정의 expected_version은 page만 검사한다.

`save_caption(session,owner_id,album_id,page_id,expected_version,caption_text)`는 review_ready/published에서만 가능하다. NFC 정규화 후 Unicode code point 80자를 검사하며 빈 문자열·공백도 사용자 값 그대로 보존한다. 같은 version의 NFC 동일값은 version/timestamp를 변경하지 않는다. 실제 변경은 page.version과 album.version을 각각 1 증가시키고 caption_edited_at/album.updated_at을 갱신한다. ai_caption과 run/task/attempt는 변경하지 않고 AI 호출은 0회다. published 수정은 status/published_at을 유지한다.

PATCH `/api/v1/albums/{album_id}/pages/{page_id}/caption`

- body: `{caption_text:string,expected_version:int>=1}` (page version).
- 200 data: `{page:Page,album_version:int}`.
- Page: `{id,position,version,upload_status,source,result,thumbnail,caption_text,sort_date,sort_date_source}`. 기존 상세와 같은 `page_dto` builder를 사용하며 source는 review_ready/published에서 null이다. ai_caption·storage_key·provider 정보는 공개하지 않는다.
- 오래된 page version은 동일값 재전송에도 409 VERSION_CONFLICT/details=`{resource_type:'page',resource_id:page_id,current_version}`다. UI는 조회·미저장 입력 비교로 응답 유실을 처리한다. Idempotency-Key를 새로 요구하지 않는다.

`publish_album(session,owner_id,album_id,expected_version)`은 album version과 review_ready/published를 검사하고 모든 활성 페이지의 연속 순서, 연결된 scoped ready 3:4 WebP result/thumbnail, ai_caption 비공백, caption_text 문자열(빈 값 허용), canonical key를 재검사한다. ready 상태가 손상되면 transaction을 변경하지 않고 409 STATE_CONFLICT다. 최초 publish는 published_at/updated_at과 status/version을 함께 commit한다. 이미 published+현재 version은 200/no-op이며 이전 version은 409다.

POST `/api/v1/albums/{album_id}/publish`

- body: `{expected_version:int>=1}` (album version).
- 200 data: `{album:AlbumSummary}`.
- AlbumSummary: `{id,title,status,version,page_count,cover,created_at,updated_at,published_at}`.

`get_viewer(session,owner_id,album_id)`는 published owner만 허용하고 publish와 같은 ready 출력 조건을 다시 확인한다. album lock 아래 일관된 페이지/글귀 snapshot을 읽고 position 순서를 반환한다.

GET `/api/v1/albums/{album_id}/viewer`

- 200 data: `{album_id,title,version,pages:[{id,position,image:MediaRef,caption_text}],media_access:MediaAccess[],music:null}`.
- MediaRef=`{asset_id,mime:'image/webp',width,height}`; MediaAccess=`{asset_id,url,expires_at}`.
- 첫 장과 다음 장의 result URL만 초기 발급한다. 나머지는 기존 POST `/albums/{id}/media-access` body `{asset_ids:[...]}`로 같은 ID를 발급한다. 유효기간은 기존 300초이며 만료 후 재발급 가능하다.
- source 원본/normalized 입력/transform_output은 published 공개 URL 발급 대상이 아니다. 실제 private GET은 기존 인증·owner/연결·ready/deleted·서명/기한 검사를 매 요청 수행한다. URL이 있어도 logout·다른 사용자·삭제 뒤 접근할 수 없다.
- music=null은 권리 확보 BGM 미준비 상태다. 음악·일반 공유를 추가하지 않았다.
