## 1. 판정과 문서 우선순위

현재 지시 → 확정 사용자 요구 → 최신 공통계약·샘플 → 상세설계의 제안·과거 미정 순으로 해석했다. 현재 문서에서 서로 양립할 수 없는 **확정 제품 요구와 최신 계약의 직접 충돌은 발견하지 못했다**. 아래는 최신 결정으로 해소된 차이, 계약의 보완 필요 사항, 아직 수치·실행 방식이 없는 항목이다. 미정 항목을 임의 정책으로 채우지 않았다.

| 과거 표현 | 현재 적용 기준 | 판정·근거 |
|---|---|---|
| HEIC는 배포 검증 후 지원 여부 결정 | HEIF/HEIC 초기 필수, 지원 제거 대신 decoder 검증 실패를 배포 실패로 처리 | 최신 사용자 결정. 명세 6·11절/상세설계 7·10절보다 계약 1·2.3·8절 우선 |
| 빈 글귀 미정, 저장 방식 미정 | AI 빈값 실패, 사용자 빈 문자열 허용, 페이지별 저장 버튼 | 계약 1·4.2·7절, JSON `client_config.data.caption_allow_empty` |
| 글자 수·용량 수치 미승인이라는 본문 | 80자·AI 목표 20~45자, 1~50장, 20MiB/300MiB/4천만 픽셀 | 상세설계 10·11절에서 승인, 계약 2.1·4.3절로 구체화 |
| 제목 PATCH, 단일 active_stage 예시 | 제목 변경 API 없음, tasks별 진행 표시 | 상세설계 5절의 과거 예시 대신 계약 3.1·4.2·4.4절 |
| 제작자 감상/NFC 예외 미정 | 로그인한 소유자 감상, 공유·NFC 제외 | 계약 1절. 명세 3.5절은 현재 인수 범위 아님 |
| 정규화 JPEG/PNG | normalized·AI 출력·result·thumbnail WebP | 계약 8절에서 v1.1 대체 명시 |
| 이미지 모델 소량 검증 후 선정 | GPT Image 2 기본 모델, 사용자 품질 확인을 개발 시작 전 반복하지 않음 | 계약 1·7절. 운영 시간·비용·timeout·실제 adapter 식별자 검증은 남음 |
| action_required에서 완료로 가는 화살표 누락 | 원래 unknown 결과 회수로 전체 완료 시 review_ready 가능 | 상세설계 4절 표보다 계약 3.1~3.2절 우선 |

제품 결정은 사진 1장=1페이지, 사용자 순서, 원본 분석, 비율 분기, 전 페이지 완료 후 편집, 소유자 감상 및 제외 범위다. UUID·version·lease/fence·outbox·polling·WebP 인코딩 설정은 현재 계약의 구현 기준이며 사용자 가치 요구와 구분한다. React/FastAPI/PostgreSQL/Render/R2 구성 그림(상세설계 3절), Python decoder 명시 및 repository 구현(계약 2.3·5절)은 문서에 존재하는 기술 선택이다. 이번 조사는 이를 새로 승인하거나 스택 결정 완료로 선언하지 않는다. 다른 스택을 선택하면 해당 기술 명시와 공개 계약을 구분해 총괄이 변경 영향을 정리해야 한다.

기반 작업의 완료는 mock 실행·독립 환경 확인이고, 실제 AI/OAuth/저장소 연동 완료와 구분한다. 합류점은 계약 6절/오케스트레이션 4절의 `로그인→초안→검증 업로드→접수`, `실제 AI→영속 결과→review_ready`, `글귀 저장→publish→viewer→삭제` 순서다. 배포 사업자·큐 제품이 정해지기 전에도 기준은 준비할 수 있으나 실제 테스트 실행 명령이나 성공 결과를 미리 만들지 않는다.

## 7. 문서 점검 결과와 한계

- 지정된 여섯 문서/JSON을 읽고 절·key를 대조했다. JSON 파싱과 보고서의 로컬 링크 대상·명시한 JSON 경로 존재 여부를 확인했다.
- 현재 JSON은 정상/일부 실패/unknown/완료, passthrough, HEIC 예약 및 정규화 실패를 제공한다. 빈 본문·BGM·만료 업로드·동의/인증/한도 오류·혼합 unknown/failed·50장 자료는 제공하지 않으므로 후속 fixture가 필요하다.
- 실제 제품 테스트·이미지 변환·OAuth·저장소·AI 호출·비용 측정·모바일 실행·배포는 수행하지 않았다. 본 보고서는 계약 준수나 구현 성공의 증거가 아니다.
- 공통계약 변경 없음. D01~D13은 총괄에게 전달할 보완/결정 목록이며 이 보고서로 새 정책을 확정하지 않는다.
