## 구현 경계

- `FakeExecutor(sessions, LocalStorage)`는 `execute(attempt_id,stage)`로 기존 Runner에 주입한다. APP_ENV=local 및 DEV_AI_ENABLED=true일 때만 worker bootstrap이 설치하며 원래 run의 execution_mode/provider/model을 local_fake/fake-canvas-v1/fake-sentence-v1로 검사한다. 외부 SDK/네트워크 호출은 없다.
- `_context`는 현재 attempt·task fence/lease·owner/album/page·입력 snapshot을 재검사한다. caption/image 모두 같은 normalized ID와 SHA를 사용하고 실제 파일 크기/checksum을 실행 전후 확인한다. optimize는 image task의 보존 output_asset_id를 사용한다. portrait는 Task1 passthrough이므로 image execute/attempt가 0이고 caption/optimize는 수행한다.
- `fake_transform(normalized_path,max_edge=4096)`와 `optimize_in_process(path,config)`는 기존 `_run_child`의 512MiB RSS/120초/취소시 kill+wait 경계를 재사용한다. 3k×4k canvas에 전체 사진을 비율 유지·확대 없이 배치하고 배경은 #ead8bb다. CPU Pillow 처리는 subprocess이며 디스크 I/O는 thread로 분리한다.
- normalized/source bytes·role은 유지한다. 표시 조건을 충족한 WebP는 result에 bytes를 복사하고 재손실 인코딩하지 않는다. 축소가 필요하면 snapshot result quality를, 결과 thumbnail은 snapshot thumbnail edge/quality를 적용한다. 결과 thumbnail은 내부 `result_thumbnail` 키·공개 MediaAsset.role=thumbnail로 저장한다. 초안 `thumbnail`은 덮어쓰지 않는다.
- canonical 키에 transform_output/result_thumbnail을 추가하고 scoped cleanup·deleted sweep은 두 thumbnail과 중간 파일·아직 DB 미연결 결과도 정리한다. transform_output/source는 기존 미디어 접근 정책으로 공개 URL 발급하지 않는다. media-access는 owner/album/page/role의 canonical 경로도 확인한다.
- stage output은 deterministic UUID5 asset으로 저장한다. 파일 저장 전에 pending metadata/checksum을 commit하여 저장 뒤 crash를 다시 찾으며, 저장 후 현재 fence/삭제 여부를 재검사한다. 기존 ResultStore envelope와 Attempt 발송 경계를 유지한다. 복구는 원래 envelope/DB 보존 응답/이미 저장된 transform_output만 회수하며 unknown에서 execute를 다시 호출하지 않는다.
- typed fake 사전 검증 실패는 명확한 not_sent/failed로 처리한다. optimize 저장 실패는 MEDIA_SAVE_FAILED/safe_to_retry/persisted local이며 resume 뒤 원래 transform_output/normalized만 읽는다. 성공 task·AI 응답은 다시 실행하지 않는다. Runner는 prepare에서 run snapshot attempt_budget도 다시 검사한다.
- `recompute_completion(session,album,run)`은 caller가 소유한 settlement transaction에서 실행한다. snapshot의 모든 page에 세 succeeded task, scoped ready 3:4 WebP result/thumbnail, ai_caption 및 초기 caption_text가 있어야 run=succeeded/finished_at과 album=review_ready/updated_at/version을 함께 갱신한다. caption은 ai_caption을 초기화하되 사용자가 저장한 caption_text/caption_edited_at을 덮어쓰지 않는다. live settlement와 recovery가 같은 함수를 사용한다.
- Runner heartbeat는 독립 DB session으로 유지한다. heartbeat 실패/lease 상실·shutdown은 executor 작업을 취소하며 media child를 reap한다. worker entrypoint의 SIGTERM도 진행 중 fake work를 취소하고 세션 engine을 해제한다.
