### 401 입력 보존 기준 교정 (위 과도한 정리 Ruling 대체)

총괄이 기존 승인 업로드의 same-owner 재로그인 File/예약의도 및 새 CSRF PUT 재전송 기준을 재확인했다. 401에서도 File/intent를 삭제하던 앞선 Ruling은 잘못된 확대였고 이 항목으로 대체한다. `resetSession(cache,'expired')`는 private query·signed URL 화면을 제거하고 session-expired 신호로 요청만 abort한다. 기존 업로드 File/예약의도·초안 생성 key·새 생성/재개/publish key+body·review text/baseline/page.version은 같은 owner의 모듈 메모리에 유지한다. 명시 logout은 전부 삭제하며 다른 owner 인증은 clear-private-memory로 이전 개인 메모리를 비우되 새 사용자의 mounted 요청을 abort하지 않는다. 저장소 persistence는 추가하지 않는다.

같은 사용자 key/body 보존·다른 사용자 전환의 명시 RED는 `/tmp/mori-generation-expiry-intent-red.log`의 2 failed/1 passed다. 총괄 검토의 401 보존 기준을 반영하여 세션 관리·Upload hook·private mutation hook을 교정했다. 이는 UI의 응답 실패 입력 보존과 기존 sameowner PUT/새 CSRF 정책을 함께 유지하는 수정이다.
