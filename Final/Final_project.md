1. 미션 소개
5개월 동안 배운 것들을 이제 하나의 서비스로 증명할 차례입니다.

아이디어에서 멈추는 게 아니라, 실제로 배포하고 사용자 피드백을 받는 것까지가 이 프로젝트입니다.

AI 도구를 자유자재로 활용해서 문제를 해결하는 사람 — 그 역량을 직접 보여주는 가장 확실한 방법입니다.

Final Project는 5개월간의 코디세이 AI 네이티브 여정을 완결 짓는 최종 캡스톤 프로젝트입니다.

AI 도구 학습부터 Python 기반 AI 활용, AI Agent 개발까지 축적해 온 모든 역량을 집대성하여 실제 사용자에게 가치를 제공하는 AI 기반 서비스를 구현합니다.

본 미션에서는 자율 주제로 팀 단위(또는 개인)로 생성형 AI와 AI Agent를 활용한 서비스를 기획부터 배포까지 주도적으로 수행합니다.

단순한 API 호출을 넘어 "문제 정의 → 서비스 설계 → AI Agent/워크플로우 구축 → 프론트엔드 연동 → 배포 및 사용자 피드백 반영"으로 이어지는 AI Native 서비스 개발 전 주기를 경험합니다.

이 프로젝트는 AI 도구를 자유자재로 활용하여 문제를 해결하는 AI Native 개발자로서 여러분의 역량을 입증할 가장 확실한 포트폴리오가 될 것입니다.

# AI 기반 개인화 학습 코치 서비스

## 프로젝트 소개
사용자의 학습 목표와 진행 상황을 파악하여 맞춤형 학습 계획을 수립하고,
일일 학습 리마인더와 진도 체크를 제공하는 AI 학습 코치 서비스입니다.
RAG를 통해 학습 자료를 검색하고, Long-term Memory로 사용자별 학습 이력을 관리합니다.

## 팀원 및 역할
| 이름 | 역할 | 담당 업무 |
|------|------|-----------|
| 홍길동 | PM / Backend | 프로젝트 관리, AI Agent 개발, API 설계 |
| 김철수 | Frontend | 채팅 인터페이스, 대시보드 개발 |
| 이영희 | AI/Data | RAG 파이프라인, 프롬프트 설계, 벡터 DB 구축 |

## 기술 스택
- **AI**: OpenAI API, LangChain, Pinecone (Vector DB)
- **Backend**: FastAPI, Render
- **Frontend**: HTML, CSS, Javascript
- **Infra**: Vercel, Supabase, GitHub Actions
- **자동화**: n8n (일일 리마인더 발송)

## 시스템 아키텍처
(아키텍처 다이어그램 이미지)

## 핵심 AI 활용

### 1. AI Agent 구조
- Planning Agent: 사용자 목표 분석 → 학습 계획 수립
- Coaching Agent: 일일 진도 체크 → 피드백 생성

### 2. RAG 파이프라인
- 학습 자료 임베딩 → Pinecone 저장
- 사용자 질문 → 관련 자료 검색 → 맥락 기반 답변

### 3. Long-term Memory
- 사용자별 학습 이력, 선호도, 강점/약점 저장
- 대화 시 이전 맥락 자동 로드

## 실행 방법
### 요구사항
- Python 3.10+
- Node.js 18+

cd project

# 요구사항 정의서

## 1. 개요
- 프로젝트명: AI 기반 개인화 학습 코치 서비스
- 목적: 자기주도 학습자를 위한 AI 기반 맞춤형 학습 관리
- 대상 사용자: 자격증/어학 등 목표 기반 학습자

## 2. 기능 요구사항

| ID | 기능명 | 설명 | 우선순위 |
|----|--------|------|----------|
| FR-01 | 학습 목표 설정 | 사용자의 학습 목표와 기간을 입력받아 저장 | Must |
| FR-02 | AI 학습 계획 생성 | 목표 기반 맞춤형 일일/주간 학습 계획 생성 | Must |
| FR-03 | Q&A 챗봇 | RAG 기반 학습 자료 검색 및 답변 생성 | Must |
| FR-04 | 진도 체크 | 일일 학습 완료 여부 기록 및 피드백 | Must |
| FR-05 | 학습 리마인더 | 설정 시간에 학습 알림 자동 발송 | Should |
| FR-06 | 진행 대시보드 | 학습 진도 및 통계 시각화 | Should |
| FR-07 | 학습 자료 업로드 | 사용자 자료 업로드 및 RAG 인덱싱 | Could |

| ID | 항목 | 요구사항 |
|----|------|----------|
| NFR-01 | 응답 속도 | AI 응답 5초 이내 |

## 4. AI 활용 명세

| 기능 | AI 활용 방식 | 상세 설명 |
|------|-------------|----------|
