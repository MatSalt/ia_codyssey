# B1-2 미션 실행 계획

## 제출물 요약

| # | 파일 | 규격 |
|---|------|------|
| 1 | 스토리보드 PDF | 브랜드 아이덴티티 + 씬별 필수 필드 완비 |
| 2 | 광고 영상 MP4 | 10초 이내, 720p 이상, H.264/AAC |

---

## 제작 단계

### 1단계: 브랜드 기획
- 브랜드명, 타겟, 톤앤매너, USP 확정
- 광고 목적(인지/전환/리텐션) 결정
- 핵심 메시지 한 문장으로 정리

### 2단계: 스토리보드 초안 작성
- 씬 수 결정 (크레딧 절약을 위해 3~4씬 권장)
- 씬별 필수 필드 채우기:
  - 씬 번호 / 씬 길이(초)
  - 목표 메시지 (한 문장)
  - 화면 구성 (구도/피사체/배경/텍스트 유무)
  - 내레이션 또는 화면 카피
  - 사용 도구 + 사용 목적
  - 입력 프롬프트 원문 + 출력 결과 요약
  - 결과 파일명 또는 링크
- 최소 1개 씬에 프롬프트 수정 전/후 기록 (의도 → 문제 → 수정 내용 → 결과 변화)

### 3단계: 이미지 생성
- 스타일 레퍼런스(sref/cref 또는 ControlNet) 고정하여 씬 간 일관성 유지
- 스토리보드 씬 순서대로 생성
- 파일명 규칙 통일: `scene01_keyvisual.png` 형식 권장

### 4단계: 비디오 생성/변환
- 이미지 → 영상 변환 (Image-to-Video) 방식 권장 (크레딧 절약)
- 파일명 규칙 통일: `scene01_motion.mp4` 형식 권장

### 5단계: 오디오 생성
- BGM + 나레이션 or 효과음 중 택 (최소 1개 필수)
- 파일명 규칙 통일: `scene01_bgm.wav` 형식 권장

### 6단계: 편집 통합
- CapCut / Premiere Pro 등으로 컷 편집
- 마지막 3~5초에 로고/브랜드명/슬로건/CTA 중 1개 이상 삽입
- 자막, 색보정, 오디오 레벨 조정
- MP4 내보내기 (H.264, AAC, 720p 이상)

### 7단계: 스토리보드 PDF 최종화
- 모든 씬 필드 최종 확인 및 실제 파일명/링크 업데이트
- PDF 내보내기
