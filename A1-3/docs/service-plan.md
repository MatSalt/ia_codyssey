# Levelly 서비스 기획서

## 목적과 타겟

영어 원문이 어렵게 느껴지는 한국어 사용자가 동일한 내용을 A1·A2·B1·B2 수준으로 비교하며 공부하도록 돕는다. 짧은 기사·이메일·책 속 문장을 읽는 초급~중상급 학습자가 대상이다. 쉬운 문장으로 의미를 먼저 이해하고, 다른 레벨의 어휘와 문장 구조를 비교하는 것이 핵심 가치다.

## 페이지 구성

한 페이지에 메뉴로 이동 가능한 3개 섹션을 제공한다.

1. 소개: 서비스 목적과 사용 방법, 네 레벨의 시각적 소개.
2. 레벨 변환: 원문 입력, 샘플 입력, 변환 결과 탭과 표현 설명.
3. 레벨 가이드: 네 수준의 특징과 같은 의미를 표현하는 고정 예시.

메뉴는 앵커 링크로 각 섹션에 이동한다. 390px 모바일, 768px 태블릿, 1440px 데스크톱에서 확인한다. 데스크톱은 입력·출력을 좌우로, 모바일은 위아래로 배치한다.

## 핵심 기능과 AI 입출력

- 입력: 앞뒤 공백을 제거한 영어 원문 1~1,500자. 한국어 설명이 일부 섞인 글은 허용한다.
- 처리: 브라우저 → fetch('/api/rewrite') → Python Vercel Function → Gemini Developer API.
- 한 번의 생성 요청으로 A1·A2·B1·B2 결과를 모두 받는다. 레벨 탭 변경은 추가 API 요청을 만들지 않는다.
- 출력: 레벨별 영어 변환문, 최대 2개 표현 변화, 한국어 이유와 학습 팁.
- 원문 의미·숫자·날짜·고유명사·부정·불확실성을 유지하도록 지시한다. 질문은 답하지 않고 질문 형태로 변환한다.
- 결과의 원문을 별도로 보존하여 요청 중 입력을 수정해도 다른 글의 결과로 오인하지 않도록 한다.
- 등급은 학습 목표 수준이며 CEFR 인증이나 정밀 난이도 판정이 아니다.

## 오류 처리

| 상황 | 동작 |
|---|---|
| 빈 입력·1,500자 초과 | 브라우저에서 안내하고 요청하지 않음. 서버에서도 재검증 |
| 영문 내용 없음 | 422 안내 |
| 무료 한도 초과 | 429 안내. 자동 재시도·유료 전환 없음 |
| 외부 API 오류·비정상 JSON·결과 누락 | 502 안내. 부분 결과를 완성본으로 표시하지 않음 |
| 응답 지연 | 서버 호출 25초, 브라우저 30초 기준으로 타임아웃 안내 |
| 연결 설정 없음 | 500 안내. 비밀 값·내부 예외는 노출하지 않음 |

모든 실패 후 원문을 유지하고 제출 버튼을 복구한다. 호출 중에는 중복 제출을 막는다.

## 기술과 운영

- 순수 HTML/CSS/JavaScript. 프론트 프레임워크 없음.
- `api/rewrite.py`의 Python Flask 앱을 Vercel Function으로 실행. Flask는 백엔드 HTTP 처리에만 사용한다.
- Gemini 무료 구간으로 시작한다. 환경 변수 `GEMINI_MODEL`로 계정에서 사용 가능한 모델을 설정한다.
- `GEMINI_API_KEY`는 서버 환경 변수에서만 읽는다. 코드·로그·증빙에 키를 남기지 않는다.
- 서비스 자체에는 글 저장·로그인·DB가 없다. 입력은 Gemini 처리에 전송되며 Google의 데이터 처리 정책이 적용된다.
- 외부 원문·AI 결과는 HTML로 해석하지 않고 textContent로 표시한다.
