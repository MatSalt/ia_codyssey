## 완료와 확인 범위

단계2·3·4 필수 구현·실제 연결·배포·제출 자료 준비를 완료했다. AI 호출 실패 시 저장하지 않음,0 기준값/null,지연·오류 UI 및 동시 삭제 경쟁은 합성 테스트로 확인했다. 실제 서비스에서는 원본을 훼손하지 않는 정상 흐름만 검증했다. AI 답변은 생성 결과에 따라 달라질 수 있으며 외부 서비스의 지속 가용성을 보장하는 테스트는 아니다.

서비스 계정과 virtual key는 Git에 포함되지 않는다. 원본 CSV도 수정하지 않았다. 실제 공개 배포에서 촬영했으며 응답 대체나 화면 내용 조작을 하지 않았다. 저장된 시연 대화1개(질문2개/답변2개)는 불러오기 확인을 위해 남겼다. 보너스 항목은 수행하지 않았다.
