# LLM 모델 비교·선정 보고서 작성 계획서

## 1. 목적

이 계획서는 최종 산출물 중 하나인 **LLM 모델 비교·선정 보고서**를 작성하기 위해 필요한 작업을 단계별로 정리한 문서입니다.

이번 비교 과업은 우리 서비스의 메타 광고 결과표인 `0621_meta_ad_report.csv`를 정리하고, 광고 성과를 해석하는 것입니다.

최종 보고서의 목표는 서로 다른 3개 이상의 LLM에게 동일한 광고 성과 분석 과업을 맡겨보고, 결과를 정해진 평가 축에 따라 비교한 뒤, **광고 데이터 해석 업무에 가장 적합한 모델**을 근거 있게 선정하는 것입니다.

## 2. 분석 대상 데이터

분석에 사용할 원본 데이터:

```text
B1-1/docs/0621_meta_ad_report.csv
```

데이터 개요:

- 데이터 성격: 메타 광고 성과 리포트
- 보고 기간: 2026-06-01 ~ 2026-06-21
- 주요 분석 단위:
  - 광고 이름
  - 연령
  - 성별
- 주요 지표:
  - 도달
  - 노출
  - 빈도
  - 지출 금액(KRW)
  - CPC(링크 클릭당 비용)
  - 페이지 참여
  - 동영상 3초 이상 재생
  - 링크 클릭
  - CTR(링크 클릭률)
  - 랜딩 페이지 조회
  - 제품 맞춤 주문
  - 콘텐츠 조회
  - 웹사이트 등록 완료
  - 웹사이트 구매

주의할 점:

- 첫 번째 데이터 행은 전체 합계로 보입니다. 광고 이름, 연령, 성별이 비어 있고 전체 지표가 집계되어 있습니다.
- 이후 행은 광고 이름, 연령, 성별 기준으로 세분화되어 있습니다.
- 일부 셀은 비어 있습니다. 비어 있는 값은 0인지, 미집계인지, 해당 없음인지 LLM이 임의로 단정하면 안 됩니다.
- `웹사이트 구매`, `제품 맞춤 주문`, `웹사이트 등록 완료`처럼 전환 관련 지표는 해석 시 특히 조심해야 합니다.

완성할 보고서에는 최소한 아래 항목이 포함되어야 합니다.

- 모델별 사용 환경

  - API
- 사용 날짜
- 요금제

  - 유료
- 주요 설정

## 4. 작업 단계

### 4.1 1단계: 비교할 업무 과업 정의하기

이번 비교 과업은 아래와 같이 정의합니다.

```text
비교 과업: 메타 광고 결과표 정리 및 성과 해석
타겟 사용자: 마케팅 담당자, 서비스 운영자, 대표 또는 의사결정자
입력 데이터: 메타 광고 성과 CSV
출력 형식: 핵심 요약 / 주요 지표 해석 / 우수 세그먼트 / 비효율 세그먼트 / 개선 제안 / 확인 필요 항목
```

이 과업에서 LLM이 해야 할 일:

- 광고 성과 데이터를 표 기반으로 이해한다.
- 전체 성과를 간단히 요약한다.
- 광고 소재별 성과 차이를 해석한다.
- 연령/성별 세그먼트별 성과 차이를 해석한다.
- CTR, CPC, 랜딩 페이지 조회, 등록 완료, 구매 등 주요 지표를 연결해 판단한다.
- 성과가 좋은 조합과 비효율적인 조합을 구분한다.
- 다음 액션을 실무적으로 제안한다.
- 데이터에 없는 내용은 추측하지 않고 "확인 필요"로 분리한다.

이 과업에서 특히 중요한 점:

- 숫자를 잘못 읽거나 임의로 계산하지 않아야 합니다.
- 빈 셀을 0으로 단정하지 않아야 합니다.
- 광고 성과가 좋은 이유를 데이터 근거 없이 만들어내면 안 됩니다.
- 단순 요약이 아니라 의사결정에 도움이 되는 해석을 제공해야 합니다.

### 4.2 2단계: 비교 대상 모델 선정하기

서로 다른 LLM 3종 이상을 선택합니다. 이번 비교에서는 아래 3개 모델을 사용합니다.

비교 대상 모델:

| 번호 | 모델명 | 사용 환경 | 요금제 | 비고 |
| --- | --- | --- | --- | --- |
| 1 | GPT 5.5 | ChatGPT 웹 | 확인 필요 | 데이터 정리, 수치 해석, 실행 제안 품질 확인 |
| 2 | Gemini 2.5 Pro | Gemini 웹 | 확인 필요 | 표 데이터 이해, 광고 성과 해석, 수치 기반 추론 품질 확인 |
| 3 | Claude Sonnet 4.6 | Claude 웹 | 확인 필요 | 긴 문맥 처리, 보고서형 문장 품질, 근거 중심 해석 확인 |

실제 보고서 작성 시에는 모델명을 사용 화면에 표시된 이름 기준으로 정확히 기록합니다. 예를 들어 화면에 `GPT-5.5`, `Gemini 2.5 Pro`, `Claude Sonnet 4.6`처럼 표시된다면 그 표기를 그대로 사용합니다.

이 단계에서 기록할 내용:

- 모델명
- 사용 채널
- 사용 날짜
- 요금제
- 주요 설정
- 파일 업로드 가능 여부
- CSV를 직접 업로드했는지, 일부 데이터를 프롬프트에 붙여넣었는지
- 무료 버전 사용 시 제한된 점

주의할 점:

- 모델명은 가능한 한 정확히 적습니다.
- 웹에서 사용해 설정값을 알 수 없다면 "확인 불가"라고 적습니다.
- 파일 업로드 기능을 사용한 모델과 텍스트 붙여넣기만 사용한 모델은 조건 차이를 반드시 기록합니다.

### 4.3 3단계: 동일 입력 프롬프트 만들기

모든 모델에 동일하게 입력할 테스트 프롬프트를 만듭니다.

프롬프트에는 다음 요소가 들어가야 합니다.

- 업무 목적
- 분석 대상 파일
- 주요 지표
- 출력 형식
- 판단 기준
- 금지 사항
- 확인 필요 항목 처리 방식

최종 테스트 프롬프트 초안:

```text
너는 퍼포먼스 마케팅 데이터를 분석하는 마케팅 애널리스트야.
첨부한 메타 광고 성과 CSV를 읽고, 우리 서비스의 광고 성과를 의사결정자가 이해하기 쉽게 정리해줘.

[분석 대상]
- 파일명: 0621_meta_ad_report.csv
- 보고 기간: 2026-06-01 ~ 2026-06-21
- 데이터 기준: 광고 이름, 연령, 성별
- 첫 번째 데이터 행은 광고 이름/연령/성별이 비어 있는 전체 합계 행으로 간주해줘.
- 이후 행은 광고 이름, 연령, 성별별 세부 성과로 간주해줘.

[분석 요구사항]
1. 전체 성과를 5줄 이내로 요약해줘.
   - 총 지출, 도달, 노출, 링크 클릭, CTR, CPC, 랜딩 페이지 조회, 등록 완료, 구매를 중심으로 정리해줘.
2. 광고 소재별 성과를 비교해줘.
   - 01_edu_ad1
   - 02_memory_ad1
   - 03_100books_ad1
3. 연령/성별 기준으로 성과가 좋은 세그먼트와 비효율적인 세그먼트를 구분해줘.
4. CTR, CPC, 랜딩 페이지 조회, 제품 맞춤 주문, 웹사이트 등록 완료, 웹사이트 구매를 연결해서 해석해줘.
5. 광고 예산을 늘릴 후보, 줄이거나 중단할 후보, 추가 테스트가 필요한 후보를 구분해줘.
6. 다음 광고 운영에서 취할 액션을 3~5개 제안해줘.
7. 데이터가 부족하거나 해석에 주의가 필요한 부분은 "확인 필요"로 따로 정리해줘.

[출력 형식]
## 1. 핵심 요약
## 2. 주요 지표 해석
## 3. 광고 소재별 비교
## 4. 우수 세그먼트와 근거
## 5. 비효율 세그먼트와 근거
## 6. 예산 조정 제안
## 7. 다음 액션 제안
## 8. 확인 필요 항목

[금지 사항]
- CSV에 없는 내용을 추측하지 마.
- 빈 셀을 임의로 0이라고 단정하지 마.
- 실제 수치와 다른 값을 만들어내지 마.
- 근거 없는 마케팅 조언을 일반론처럼 쓰지 마.
- 계산이 필요한 경우 어떤 지표를 기준으로 판단했는지 밝혀줘.
- 원인을 단정하지 말고, 데이터로 확인되는 현상과 추정이 필요한 해석을 구분해줘.
- 고객의 심리, 광고 문구의 의도, 랜딩페이지 품질처럼 CSV에 없는 정보는 "확인 필요"로 분리해줘.

[작성 방식]
- 표와 bullet을 함께 사용해 읽기 쉽게 작성해줘.
- 중요한 수치는 원본 CSV 기준으로 함께 적어줘.
- 최종 결론은 의사결정자가 바로 볼 수 있게 간결하게 작성해줘.
```

파일 업로드가 불가능한 모델에는 CSV 내용을 일부 또는 전체 붙여넣어 동일한 조건에 가깝게 테스트합니다.

이 단계에서 해야 할 일:

- 위 프롬프트를 모든 모델에 동일하게 입력합니다.
- 모든 모델에 같은 프롬프트를 사용합니다.
- 파일 업로드 방식이 다르면 보고서에 조건 차이를 기록합니다.
- 가능하면 동일한 CSV 전체를 입력합니다.

### 4.4 4단계: 평가 축 정하기

모델 결과를 비교할 평가 축을 정합니다. 최소 4개 이상 필요합니다.

이번 과업에 사용할 추천 평가 축:

| 번호 | 평가 축 | 평가 기준 |
| --- | --- | --- |
| 1 | 데이터 이해 정확성 | CSV 구조, 광고명, 연령, 성별, 주요 지표를 올바르게 이해했는가? |
| 2 | 수치 해석 정확성 | CTR, CPC, 클릭, 전환 지표를 실제 값과 다르게 말하지 않았는가? |
| 3 | 인사이트 품질 | 단순 요약을 넘어 의사결정에 도움이 되는 해석을 제공했는가? |
| 4 | 형식 준수 | 요청한 8개 섹션 구조를 지켰는가? |
| 5 | 환각 억제 | 데이터에 없는 원인, 고객 특성, 캠페인 의도를 단정하지 않았는가? |
| 6 | 실행 제안의 실무성 | 다음 액션이 실제 광고 운영에 적용 가능하고 구체적인가? |
| 7 | 한국어 보고서 품질 | 문장이 자연스럽고 보고서로 제출하기 적절한가? |

점수 기준:

| 점수 | 의미 |
| --- | --- |
| 5점 | 매우 우수하며 거의 수정 없이 사용 가능 |
| 4점 | 우수하지만 일부 표현 또는 세부 검토 필요 |
| 3점 | 보통이며 중요한 수정이 일부 필요 |
| 2점 | 부족하며 결과 신뢰도가 낮음 |
| 1점 | 요구사항을 거의 충족하지 못함 |

핵심 평가 축:

- 데이터 이해 정확성
- 수치 해석 정확성
- 환각 억제
- 인사이트 품질

최종 모델 선정 시에는 평균 점수뿐 아니라 위 핵심 평가 축을 더 중요하게 봅니다.

### 4.5 5단계: 모델별 실행 결과 수집하기

선정한 모델에 동일한 프롬프트와 동일한 CSV를 입력하고 결과를 저장합니다.

저장할 내용:

- 입력한 원본 프롬프트
- 사용한 CSV 파일명
- 모델별 원본 출력
- 실행 날짜
- 사용 환경
- 파일 업로드 여부
- 특이사항
  - CSV를 제대로 읽었는지
  - 전체 합계 행과 세부 행을 구분했는지
  - 빈 셀을 어떻게 처리했는지
  - 숫자를 잘못 인용했는지
  - 근거 없는 추측을 했는지
  - 실행 제안이 구체적인지

권장 저장 방식:

```text
B1-1/docs/model_outputs/
├── gpt_output.md
├── claude_output.md
└── gemini_output.md
```

각 파일에는 아래 형식으로 기록합니다.

```text
# 모델명 실행 결과

## 사용 환경
- 모델명:
- 사용 채널:
- 요금제:
- 사용 날짜:
- 파일 업로드 여부:
- 주요 설정:

## 입력 프롬프트

## 모델 원본 출력

## 관찰 메모
```

### 4.6 6단계: 모델별 결과 요약하기

각 모델의 출력 결과를 짧게 요약합니다.

요약 시 확인할 내용:

- CSV 구조를 제대로 이해했는가?
- 전체 성과와 세그먼트별 성과를 구분했는가?
- 광고 소재별 비교가 타당한가?
- CTR, CPC, 랜딩 페이지 조회, 전환 지표를 연결해 해석했는가?
- 수치 오류가 있는가?
- 빈 셀이나 누락값을 임의로 해석했는가?
- 다음 액션이 구체적인가?

작성 예시:

```text
GPT 계열 모델은 전체 성과와 광고 소재별 비교를 빠르게 구조화했고, CTR과 CPC를 중심으로 우수 세그먼트를 잘 구분했다.
다만 일부 빈 전환 값을 0처럼 해석하는 표현이 있어 환각 억제와 누락값 처리 측면에서는 추가 검토가 필요했다.
```

### 4.7 7단계: 평가표 작성하기

모델별 점수를 표로 정리합니다.

평가표 예시:

| 평가 축 | GPT 계열 모델 | Claude 계열 모델 | Gemini 계열 모델 |
| --- | --- | --- | --- |
| 데이터 이해 정확성 |  |  |  |
| 수치 해석 정확성 |  |  |  |

수치 해석 정확성 5점: 총 지출 149,488원, 링크 클릭 294건, CTR 2.9997% 등 핵심 수치를 원본과 일치하게 인용했다.

### 4.8 8단계: 최종 모델 선정하기

평가 점수와 근거를 바탕으로 최종 모델 1개를 선택합니다.

선정 기준:

- 평균 점수가 가장 높은가?
- 핵심 평가 축에서 강한가?
- CSV의 숫자와 구조를 정확히 이해했는가?
- 광고 성과 해석이 실제 의사결정에 도움이 되는가?
- 데이터에 없는 내용을 단정하지 않았는가?
- 다음 액션 제안이 구체적이고 실행 가능한가?

주의할 점:

- 단순히 평균 점수만 보고 고르지 않습니다.
- 이번 과업에서는 **수치 해석 정확성**, **환각 억제**, **인사이트 품질**을 우선합니다.
- 마케팅 문장이 그럴듯해도 숫자를 틀리거나 없는 내용을 단정하면 낮게 평가합니다.

최종 선정 근거 예시:

```text
최종 선정 모델은 GPT 계열 모델이다.
이 모델은 메타 광고 CSV의 전체 합계와 세그먼트별 데이터를 비교적 정확히 구분했고, CTR, CPC, 랜딩 페이지 조회, 전환 지표를 연결해 해석했다.
특히 성과가 좋은 광고 소재와 세그먼트를 수치 근거와 함께 제시해 다음 예산 배분 판단에 활용하기 쉬웠다.

```
