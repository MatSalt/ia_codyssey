# v1 프롬프트 및 질문 리스트

## 1. 문서 목적

이 문서는 v2 프롬프트와 비교하기 위한 v1 버전 대화 로그를 새로 만들 때 사용할 기준 문서다.

- v1은 의도적으로 단순한 일반 지시 프롬프트만 사용한다.
- 이후 질문은 실제 대화 로그에서 사용자가 번호를 붙여 물어본 업무 질문만 모았다.
- 원본 참조 로그: `B1-1/docs/conversation_log.md`

## 2. v1 비교용 프롬프트

```text
첨부한 광고 성과 CSV를 보고 광고 성과를 분석해줘.
좋은 세그먼트와 나쁜 세그먼트를 알려주고 다음 액션도 제안해줘.
```

## 3. v1 프롬프트의 의도

v1은 아래 조건을 일부러 자세히 주지 않는 기본 프롬프트다.

- 전체 합계 행과 세부 행 구분 기준
- 빈 셀 처리 기준
- 출력 섹션 형식
- CSV에 없는 정보 추측 금지 규칙
- 계산식과 근거 제시 규칙
- 확인 필요 항목 분리 규칙

따라서 v1 대화 로그에서는 수치 오류, 빈 셀 0 단정, 형식 흔들림, 확인 필요 항목 누락 여부를 관찰한다.

## 4. v1 대화 로그 작성 방식

1. 첫 입력에는 위 v1 프롬프트만 사용한다.
2. 이후에는 아래 질문 리스트를 순서대로 입력한다.
3. 모델 답변은 수정하지 않고 원문 그대로 저장한다.
4. 마지막에 v2 로그와 비교해 문제 지점과 개선 필요 사항을 정리한다.

## 5. 실제 번호 질문 리스트

아래 질문은 `B1-1/docs/conversation_log.md`에서 사용자가 실제로 번호를 붙여 입력한 업무 질문만 추린 것이다. 대화 로그 저장 요청처럼 과업 수행과 직접 관련 없는 메타 요청은 제외했다.

### 1번 질문

```text
1. 첨부한 0621_meta_ad_report.csv를 분석해줘. 보고 기간은 2026-06-01부터 2026-06-21까지야. 첫 번째 데이터 행은 전체
  합계 행이고, 이후 행은 광고 이름/연령/성별 기준 세부 행으로 봐줘.
```

### 2번 질문

```text
2. 전체 성과만 먼저 5줄 이내로 요약해줘. 총 지출, 클릭, CTR, CPC, 랜딩 페이지 조회, 등록 완료, 구매를 꼭 포함해줘.
```

### 3번 질문

```text
3. 광고 소재별로 비교해줘. 01_edu_ad1, 02_memory_ad1, 03_100books_ad1 각각의 지출, 클릭, CTR, CPC, 랜딩 조회, 등록,
  구매를 표로 정리해줘.
```

### 4번 질문

```text
4. 연령/성별 기준으로 성과가 좋은 세그먼트 3개를 골라줘. 근거 수치를 함께 적어줘.
```

### 5번 질문

```text
5. 비효율적인 세그먼트도 3개 이상 골라줘. 단, 원본에서 빈 셀인 값은 0건이라고 단정하지 말고 "기록 없음"으로 표현해
  줘.
```

### 6번 질문

```text
6. 지금부터 보고 대상은 대표야. 같은 내용을 더 짧고 결론 중심으로 바꿔줘. 숫자는 유지해줘.
```

### 7번 질문

```text
7. 추가 조건이 있어. 구매 추적이 불안정할 수 있으니 구매 6건만 보고 예산을 크게 늘리면 안 돼. 이 조건을 반영해서 예
  산 조정안을 다시 써줘.
```

### 7번 질문 재입력

원본 로그에는 같은 7번 질문이 한 번 더 입력되어 있다. v1 로그를 엄밀히 재현하려면 아래 질문도 같은 순서로 다시 입력한다.

```text
7. 추가 조건이 있어. 구매 추적이 불안정할 수 있으니 구매 6건만 보고 예산을 크게 늘리면 안 돼. 이 조건을 반영해서 예
  산 조정안을 다시 써줘.
```

### 8번 질문

```text
8. 다음 광고 운영 액션을 딱 3개만 제안해줘. 각 액션마다 근거 수치 1개 이상을 붙여줘.
```

### 9번 질문

```text
9. CSV에 없는 내용과 확인이 필요한 내용을 따로 정리해줘. 랜딩페이지 품질, 고객 심리, 광고 문구 의도, ROAS는 단정하
  지 말아줘.
```

### 10번 질문

```text
10. 지금까지의 대화 조건을 모두 반영해서 최종 보고서를 8개 섹션 형식으로 다시 작성해줘. 그리고 마지막에 "이번 답변
  에서 지킨 조건"을 5개 bullet로 요약해줘.
```
